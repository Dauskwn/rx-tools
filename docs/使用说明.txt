====================================================================
                  RX 工具箱 V1.8.0  使用说明
====================================================================

一款专为 Garry's Mod 玩家打造的轻量级绿色辅助工具，集成了自动挤服、
桌面置顶外置准星、时间链倒计时与快捷文本管理四大实用工具。
单文件绿色免安装，支持软件内一键检查更新与 SHA256 校验自动替换。

--------------------------------------------------------------------
一、目录与文件说明
--------------------------------------------------------------------
解压后放到任意纯英文或常规目录即可双击「Rx工具箱.exe」运行：

  Rx工具箱.exe    主程序（单文件绿色版，免安装）
  使用说明.txt    本使用说明
  settings.ini    软件设置（热键、主题、准星与倒计时参数等）
  servers.txt     挤服收藏服务器列表（格式：IP:端口|备注）
  custom.txt      自定义页保存的常用快捷文本条目

* 所有配置均在运行目录自动生成或保存，删除即可恢复默认。
* 如在全屏/管理员权限运行的游戏内遇到全局热键无响应，可右键
  「Rx工具箱.exe」选择「以管理员身份运行」，或将游戏设为无边框窗口化。

--------------------------------------------------------------------
二、标签页功能介绍
--------------------------------------------------------------------

【1】挤服助手
  · 三种挤服模式：
    1) 手动档：无需配置 IP，在游戏内点击「连接」后启动挤服，工具会自动
       连续发送回车键重试。
    2) 单一 IP：在列表选中一个服务器后启动，自动切入控制台发送
       connect <IP:端口> 并回车；若发送前需先打开控制台（默认 ~ 键）。
    3) 收藏轮询：勾选多个服务器按顺序轮流发送 connect 指令尝试进入。
  · A2S 实时查询：支持单服/全列表刷新在线人数、地图与服务器名称；
    列表右键支持「立即连接」「复制 IP」「置顶」「编辑」「删除」。
  · OCR 识别进服后自动停：利用 Windows 10/11 系统自带 OCR 后台检测
    游戏画面变化及加载提示（如“正在加载插件”），识别进入后自动停止挤服
    并发出提示（可在列表下方点“系统 OCR 语言包检查 / 帮助”确认环境）。

【2】屏幕准星
  · 外置置顶全透明准星，不影响鼠标与游戏正常点击（点击穿透）。
  · 内置 6 种矢量样式：十字(带缺口) / 十字(无缺口) / 小圆点 / 空心圆 /
    圆+十字 / T 字形；支持自由调节线宽、臂长、中心间隙、中心点与颜色。
  · 自定义准星图：支持「导入准星图片…」或「粘贴图片」，支持透明底 PNG，
    黑底图片也会自动抠除纯黑背景。

【3】倒计时（时间链）
  · 桌面置顶透明数字悬浮窗，全程点击穿透，不遮挡鼠标视角操作。
  · 多预设方案：内置「标准对局」「标准对局(带标注)」等示例预设，可自由
    新建、复制、重命名与删除方案，满足不同对局或自定义计时需求。
  · 时间链事件规则：按剩余时间触发节点，支持文字变色、低/中/高频闪烁及
    叠加描边文字标注（例如关键节点提示、收尾倒计时预警等）。
  · 外观调整：支持悬浮窗锚点位置（顶左/顶中/顶右等）、偏移像素与字号。

【4】自定义（快捷文本）
  · 添加和管理常用文本卡片，点击任意卡片即可一键复制到剪贴板，按卡片
    底部或右侧面板快速增删、上下排序、编辑并保存（支持 Ctrl+S 保存）。
  · 实时筛选：顶部搜索框支持按标题或正文关键词实时过滤卡片，按 Esc
    一键清空筛选。

【5】关于与更新
  · 程序更新：支持启动时自动检查或手动点击「检查更新 / 立即更新」，
    通过 SHA256 校验与原地替换安全升级（若目录只读或网络受限，也可点
    「GitHub 发布页」或查看更新帮助地址手动下载）。
  · 包含开源仓库链接、版本更新日志、声明与 GitHub Issue 反馈入口。

--------------------------------------------------------------------
三、默认全局热键一览（可在右上角「热键设置」全部自定义）
--------------------------------------------------------------------

  F5          循环切换准星样式
  F6          开始 / 停止自动挤服
  F7          循环切换准星颜色
  F8          显示 / 隐藏屏幕准星
  F9          倒计时开始 / 重置
  Ctrl + F9   倒计时暂停 / 继续
  F10         显示 / 隐藏倒计时悬浮窗
  Ctrl + F10  关闭 / 恢复全局热键（暂时交还热键给其他程序）
  Ctrl + F11  退出 RX 工具箱

* 开启「关闭热键 (Ctrl+F10)」后，除 Ctrl+F10 与退出外的功能热键会暂时
  释放，方便打字、截图或与其他工具避让；下次启动程序时会自动恢复激活。

--------------------------------------------------------------------
四、底部状态栏与主题外观
--------------------------------------------------------------------
  · 窗口底部左侧提供三档主题切换按钮，点击循环切换：
    「护眼浅色（默认）」 → 「跟随系统」 → 「夜间深色」
    所有主界面及弹出窗口（日志、热键设置、时间链编辑等）均完整适配。
