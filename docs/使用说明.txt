====================================================================
                  RX 工具箱 V1.8.1  使用说明
====================================================================

一款专为 Garry's Mod 玩家打造的轻量级绿色辅助工具，集成了自动挤服、
桌面置顶外置准星、时间链倒计时与快捷文本管理四大实用工具。
单文件绿色免安装，支持软件内一键检查更新与 SHA256 校验自动替换。

--------------------------------------------------------------------
一、目录与文件说明
--------------------------------------------------------------------
解压后放到任意纯英文或常规目录即可双击「Rx工具箱.exe」运行：

  Rx工具箱.exe    主程序（单文件绿色版，免安装）
  使用说明.txt    本使用说明
  settings.ini    软件设置（热键、主题、准星与倒计时参数等）
  servers.txt     挤服收藏服务器列表（格式：IP:端口|备注）
  custom.txt      自定义页保存的常用快捷文本条目

* 所有配置均在运行目录自动生成或保存，删除即可恢复默认。
* 如在全屏/管理员权限运行的游戏内遇到全局热键无响应，可右键
  「Rx工具箱.exe」选择「以管理员身份运行」，或将游戏设为无边框窗口化。

--------------------------------------------------------------------
二、功能页面介绍（左侧可折叠导航栏切换）
--------------------------------------------------------------------

【1】挤服助手
  · 三种挤服模式：
    1) 手动档：无需配置 IP，在游戏内点击「连接」后启动挤服，工具会自动
       连续发送回车键重试。
    2) 单一 IP：在列表选中一个服务器后启动，自动切入控制台发送
       connect <IP:端口> 并回车；发送前会尝试打开控制台（默认 ~ 键）。
    3) 收藏轮询：勾选多个服务器按顺序轮流发送 connect 指令尝试进入。
  · A2S 实时查询与同步线上：
    - 支持单服/全列表刷新在线人数、地图、延迟与真实服务器名；
    - 点击「同步线上」（启动检查更新时也会静默增量合并）可拉取线上服务器
      列表并追加缺失服务器；凡你收藏中已存在的 IP，均原样保留你自己的备注
      与缓存名，绝不覆盖；
    - 列表右键支持「立即连接」「复制 IP」「置顶」「编辑」「删除」。
  · OCR 识别进服后自动停：利用 Windows 10/11 系统自带 OCR 后台检测
    游戏画面变化及加载提示（如“正在加载插件”），识别进入后自动停止挤服
    并发出提示（可在列表下方点“系统 OCR 语言包检查 / 帮助”确认环境）。

【2】屏幕准星
  · 外置置顶 32-bit 半透明穿透悬浮层，不影响鼠标与游戏正常点击。
  · 内置 6 种矢量样式：十字(带缺口) / 十字(无缺口) / 小圆点 / 空心圆 /
    圆+十字 / T 字形；支持调节线宽、臂长、中心间隙、中心点、黑描边、不透明度与颜色。
  · 准星方案卡片与微调：内置 4 套常用方案（最多保存 6 套自定义方案，右键支持
    重命名与删除），支持中心位置 ±20px 精细偏移归零；
  · 自定义准星图：支持「导入准星图片…」或「粘贴图片」，完整保留 PNG 半透明羽化，
    纯黑底图片也会自动抠除黑色背景。

【3】倒计时（时间链）
  · 桌面置顶透明数字悬浮窗，全程点击穿透，支持纯数字黑边或胶囊背板+进度条。
  · 多预设方案：内置「标准对局」「标准对局(带标注)」等示例预设，可自由
    新建、复制、重命名与删除方案，满足不同对局或自定义计时需求。
  · 时间链事件规则：支持在可视化时间轴直接点击/拖动定位，并按剩余时间触发
    变色、低/中/高频闪烁及叠加描边文字标注。
  · 外观调整：支持悬浮窗锚点位置（顶左/顶中/顶右等）、偏移像素与字号。

【4】自定义文案（文本工具）
  · 添加和管理常用文本卡片，点击任意卡片即可一键复制到剪贴板，支持卡片
    快速增删、上下排序、编辑并保存（Ctrl+S）与按关键词实时筛选（Esc 清空）。

【5】设置与关于与更新
  · 独立「设置」页：集中管理「外观与窗口」（三档主题、收起左侧导航栏、点关闭
    (×) 时缩进系统托盘）、「全局热键」（一键暂停与自定义）、「更新与日志」
    （开机检查更新、查看/清空日志、打开数据目录与日志大小查看）。
  · 关于与更新：支持软件内「检查更新 / 立即更新」（SHA256 校验 + 原地替换）
    与「更多设置…」快捷跳转，并提供 GitHub 发布页与 Issue 反馈入口。

--------------------------------------------------------------------
三、默认全局热键一览（可在「设置」或工具栏「热键设置」自定义）
--------------------------------------------------------------------

  F5          循环切换准星样式
  F6          开始 / 停止自动挤服
  F7          循环切换准星颜色
  F8          显示 / 隐藏屏幕准星
  F9          倒计时开始 / 重置
  Ctrl + F9   倒计时暂停 / 继续
  F10         显示 / 隐藏倒计时悬浮窗
  Ctrl + F10  关闭 / 恢复全局热键（暂时交还热键给其他程序）
  Ctrl + F11  退出 RX 工具箱

* 开启「关闭热键 (Ctrl+F10)」后，除 Ctrl+F10 与退出外的功能热键会暂时
  释放，方便打字、截图或与其他工具避让；下次启动程序时会自动恢复激活。

--------------------------------------------------------------------
四、底部交互状态栏与主题外观
--------------------------------------------------------------------
  · 窗口底部状态栏将「准星」「挤服」「倒计时」「热键」状态收拢为可点击胶囊：
    单击即可切换准星开关、跳转挤服/倒计时页面或打开热键设置；
  · 底栏右侧提供三档主题切换胶囊，点击循环切换：
    「护眼浅色（默认）」 → 「跟随系统」 → 「夜间深色」
    所有主界面及弹出窗口（日志、热键设置、时间链编辑等）均完整适配。
